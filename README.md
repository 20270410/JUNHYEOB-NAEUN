# 모바일 청첩장 (장준협 · 박나은)

## GitHub Pages로 올리는 방법
1. GitHub에서 새 저장소(Repository) 만들기 (예: wedding)
2. 이 폴더 안의 파일 전체(index.html, 이미지, bgm.mp3, GoldenGraph.ttf)를 업로드 (Add file > Upload files)
3. Settings > Pages > Branch: main / (root) 선택 후 Save
4. 1~2분 뒤 https://아이디.github.io/저장소이름/ 주소로 접속

## 참고
- 방명록은 claude.ai에서만 동작해서, 이 사이트에서는 자동으로 숨겨져요.
- 링크 복사/공유 버튼은 접속한 주소를 그대로 사용해요.
